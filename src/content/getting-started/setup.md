svelte-shadcn-components is a collection of copy-and-paste components built for Svelte 5 using [shadcn-svelte](https://shadcn-svelte.com/) and [tailwind-css](https://tailwindcss.com/). The components are ready to copy-and-paste and use it in your projects.

# Dependencies

svelte-shadcn-components relies on the following dependencies:

- [Lucide](https://lucide.dev) for icons
- [Tailwind](https://tailwindcss.com/) for styling
