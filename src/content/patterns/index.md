## What are Patterns?

Patterns are pre-built combinations and customizations of components

Take for example shadcn-ui: it comes with beautiful defaults, but sometimes you want a different look, or you need to arrange the components in some particular way. Patterns are ready-to-use snippets of code that achieve that.

## Submit a Pattern

You can submit a pattern by creating a pull request.
